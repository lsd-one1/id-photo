# 증명사진 변환

빌드 과정이 없는 정적 웹페이지입니다. 프로젝트 폴더에서 `python -m http.server 8765`를 실행한 다음 `http://localhost:8765/`를 엽니다. 사진과 결과는 브라우저 안에서 처리됩니다. 첫 사용에는 고정 버전 MediaPipe 라이브러리와 두 모델을 내려받으므로 인터넷이 필요합니다.

## 기능과 규격

- 한국 여권 35×45mm, 주민등록증·운전면허 35×45mm, 증명·반명함 30×40mm, 미국 여권·비자 50.8×50.8mm.
- JPEG 300dpi 픽셀 크기: 413×531, 354×472, 600×600. 용량은 규격별 상한을 넘지 않는 첫 JPEG 품질을 사용하며, 0.30까지 넘으면 참고용 파일만 받을 수 있습니다.
- 여권·미국은 원본 배경을 유지합니다. 주민증·반명함은 흰 배경 교체를 선택할 수 있습니다. 기관에 따라 합성 사진을 받지 않을 수 있습니다.
- 4×6인치 모음판은 사진을 줄이지 않고 가장 많이 들어가는 배치를 고릅니다. 장수가 같으면 2mm 간격을, 간격 때문에 장수가 줄면 간격 0mm(재단선만)를 씁니다.
- 크기와 위·아래 위치를 수동 보정할 수 있습니다. 결과 경고를 확인하세요.

## 규격 출처 및 확인 필요

- 한국 여권: passport.go.kr, gov.kr 여권 안내
- 주민등록증·운전면허: koroad.or.kr
- 미국 여권·비자: travel.state.gov
- 증명·반명함은 단일 법정 규격이 없는 관행값입니다.
- 확인 필요 가정: 주민증 JPEG 상한 250KB, 한국 사진 위 여백 비율 40%, 반명함 목표 머리 높이 28mm.

## 공개 검증 사진

`tests/fixtures/faces/SOURCES.md`의 미국 연방정부 공개 도메인 사진을 내려받아 같은 파일명으로 `tests/fixtures/faces/`에 둡니다. 용량 때문에 사진 파일은 Git에서 제외되며, 출처 및 사람이 표시한 원본-바로선 좌표는 `SOURCES.md`, `labels.json`에 남습니다.

## 검증

```text
node --test tests/layout.test.mjs
python tests/e2e.py
```

Node 24 는 `node --test tests/` 를 파일 경로로 읽어 실패하므로 파일을 직접 지정합니다.
